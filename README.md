# Shannic

Shannic is an Android app that lets you listen to free audio and music without ads. Shannic is not responsible for the content of the audio or music you listen to.

## Features

- Search audios / music
- Autoplay
- Favorites
- Import favorites from Spotify
- Offline

## Next Features

- Playlists
- Import playlists from Spotify
- Port to desktop?

Want some new features? Open an issue and i will try to work on it.
