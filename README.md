# Shannic

Shannic is an android app to listen audios / music for free without ads. Shannic is not responsible of the content of the audios / music you listen.

## Features

- Search audios / music
- Autoplay
- Favorites
- Import favorites from Spotify
- Offline

## Next Features

- Playlists
- Import playlists from Spotify
- Port to desktop?

Want some new features? Open an issue and i will try to work on it.
