# Shannic

Shannic is an android hybrid app to listen to your favorite music / audios for free without ads.

## Features

- Search audios / music
- Autoplay
- Favorites
- Import favorites from Spotify
- Offline

## Next Features

- Playlists
- Import playlists from Spotify
- Port to desktop?

Want some new features? Open an issue and i will try to work on it.
